# A supervised ear for authored lines

Keep the production decision on the ordinary OneJev. Compare a frozen and a
lightly fitted selector for English remarks. Use the previous six external
voice-training PRs in both directions. Hold out Underscore #3026, npm/ini
#123, and node-semver #870 in both directions. These cases are new to the
voice experiments. All have preexisting original OneJev receipts.

Give the selector the file, recorded vote, and admitted expected and observed
outputs. For each review ask two questions using the same instruction. In
the taste comparison both remarks accurately report the run, one is dry and
characterful and the other is plain. In the grounding comparison both have
character, one describes the opposite execution. Write both candidates for
each case before the first selector pass. The intended preference belongs to
the author of these pilot lines. Oleg's later preferences remain independent.

Present every pair in both letter orders. Use the same frozen OneJev weights,
32 fixed projected residual features and bias as the first experiment. This
time fit just the A and B output rows with one supervised letter per prompt,
full-vocabulary cross entropy, 200 full-batch steps, learning rate 0.25 and
L2 0.002. Read the A/B probabilities at the first answer position. Archive
every selection, its options, and the original and fitted probabilities.

Report accuracy per presentation and both orders correct per case separately
for taste and grounding. The pilot must pass six of six cases on both axes
in both orders to reach a blind audition with Oleg. No change to live prose
or the release weights on the strength of this panel alone.
