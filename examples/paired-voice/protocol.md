# Can Jovovich tell the fix from the rollback in her own words?

OneJev first reviews the patch and records its verdict, probabilities and
execution witness. AML then asks for a spoken English remark about that
particular result. The second pass gets the same voice prompt as the first
voice audition. It has no write path to the signed review.

## Material

Train on the six repair/reversal pairs in the first voice pilot. Each direction
has two authored references: the earlier line and the second reading in
`references.tsv`. Give each reference equal weight. Keep project, PR, direction,
hashes and target text outside the prompt. Only the `state` field goes to AML.

Audition on inih #140 (inline comment), inih #188 (first error line),
node-semver #867 (subset) and node-semver #872 (prerelease membership). Each
fix is paired with its exact rollback. These cases have decision receipts in
the release trial and have never supplied a voice training target. The eight
audition states contain no reference remarks. Keep all eight, including any
unfavorable vote. The implementation must derive both directions from the
pinned receipts and check that their head and base revisions trade places.

## First fit

Use one rank-4 LoRA with alpha 4 on the last language block's MLP down
projection. Its input is 3,584 SwiGLU activations and its output is 1,024
residual channels. This gives 18,432 trainable coefficients. At the pinned
NoTorch revision the residual callback fires after the projection and skip
addition. The native voice path needs access to the SwiGLU vector before the
projection. Verify zero-initialized output factors reproduce the base logits
and finite-difference-check a gradient on a tiny fixture before fitting.

Freeze all original weights. Train only on continuation tokens and end of
turn, with full-vocabulary cross-entropy averaged per reference, AdamW at
0.001 (betas 0.9/0.999, epsilon 1e-8, zero decay), seed 42, batches of four
references, 12 passes, shuffled each pass. Use the final update. Keep the
adapter in a separate artifact. Run the stock voice and the fitted voice with
the same AML bytes, greedy decoding and 32-token cap. Keep raw token IDs,
generated bytes and stop reason for every row. Never select a checkpoint
using the four audition pairs.

## Listening test

Score each remark against the executed head. It must finish within the cap,
identify something concrete about that particular result, and agree with the
recorded verdict. For each PR, shuffle its two remarks and match them back to
the two receipts. Count a pair only when both remarks pass individually and
the matching is unambiguous. Swapping in an all-purpose compliment or
complaint must fail the concrete-result test. Record every failure verbatim.

A candidate enters the blind voice comparison with eight passing remarks,
four matched pairs and no duplicate line. For each passing scene compare the
base and candidate remarks with anonymous, shuffled identities; let Oleg pick
either or tie. To enter the live CLI, require at least five candidate wins out
of eight, and rerun the ordinary decision regressions with identical verdicts
and probabilities. Archive both voices and the outcome.
